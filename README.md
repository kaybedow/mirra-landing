# Мірра

Демо лендинг ювелірного бренду для портфоліо. Бренд і назви прикрас вигадані.

Сайт: https://kaybedow.github.io/mirra-landing/

Узяв по одному фото каблучки і підвіски з безкоштовних фотостоків і зробив з них повний набір кадрів, як для карточки інтернет-магазину: головне фото на білому, вигляд згори, макро, на тілі, лайфстайл.

На сторінці:
- галерея товару: мініатюри міняють фото, на компʼютері лупа за курсором
- повзунок до і після: стокове фото проти готового кадру
- блок з помилками AI і тим, як я їх виправляв

Як робив: до кожного промпту в Gemini (Nano Banana) додавав оригінал і перелічував деталі, які не можна міняти. Кожен кадр з оригіналу, а не з попередньої генерації, щоб помилки не накопичувались. Правки в Photopea.

HTML, CSS і JS без фреймворків.
